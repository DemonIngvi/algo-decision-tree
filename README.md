# Дерево выбора алгоритма

Интерактивное дерево решений для алгоритмических и live-coding собеседований (Go).

**Открыть:** https://demoningvi.github.io/algo-decision-tree/

- Слева дерево `if / else`: условия ведут к алгоритмам (**да** вправо, **нет** вниз).
- Справа описание выбранного алгоритма: когда выбирать, идея, сложность, задачи LeetCode, типичная ловушка и пример решения на Go.
- Один HTML-файл без зависимостей, светлая и тёмная тема.

Часть разборов и ошибок взята из видео:
[два метода на 80% задач](https://youtu.be/SknJzSY34j4) ·
[in-memory кэш на Go-собесе](https://youtu.be/QSfzdf3Dwb0) ·
[мок-собес Ozon, алгоритмы](https://youtu.be/oGMB4jDJGro) ·
[задача на горутины, Авито](https://youtu.be/mB13FSDzcGo).

Код примеров не запускался компилятором; использует `min`/`max` (Go 1.21+) и захват переменной цикла (Go 1.22+).
